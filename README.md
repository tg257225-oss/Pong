# Pong
Pong is a classic desktop ping pong game (with some variations) made in Python.
### ![Main Menu](Assets/practicallyfinished.png)
### ![Game](Assets/ingame.png)
## Overview
There are currently 3 different game modes. The first mode, 'Normal', is your standard Pong game. Everything stays the same the entire duration of the game. The second mode, 'Speed', adds a nice twist to the game. Everytime 
the ball collides with something (whether its the wall or the paddles), it increases in speed by a certain factor until someone scores a point.
